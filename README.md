# 智关 Agent 9610

面向 9610 跨境电商零售出口的智能申报预检与制单辅助 Agent。

负责单据识别、归类推理、规则核验、缺口提示、风险分流和可追溯的制单建议。**不替代海关正式审核，也未接通正式申报接口**——它定位在申报前的预检与制单环节，把"人核对单"变成"系统预检 + 人复核"。

## 解决什么问题

9610 零售出口单票金额小、票数多。小微卖家普遍没有专职报关员，把单据交给货代后信息二次转写，错漏无人兜底；而税则、申报要素、管制参数年年调整，靠经验记不住。

一张商业发票进来，系统要回答四个问题：

1. 这个货归哪个 HS 编码（归类）
2. 申报要素缺什么（缺口）
3. 有没有管制 / 危险品 / 商标线索（风险）
4. 能不能自动拟单，还是要人复核（分流）

## 核心机制

### 四域六槽架构

```
Coordinator（意图路由）
├── transport   运输询价
├── booking     订舱
├── customs     报关（核心）
│   └── CustomsOrchestrator 六槽流水线
│       A 归类推理  → B 三单预检 → C 清单合规
│       D 风险预判  → E 归并     → F 节点监控
└── tracking    链路追踪
```

### A/B/C 三级分流

定级只看规则引擎的 `risk_flags`（severity 与 type），模型自我评价不参与：

| 级别 | 触发条件 | 处置 |
|---|---|---|
| A 自动拟单 | 高置信 + 无风险命中 | 直接生成清单草稿 |
| B 人工复核 | 商标线索 / 低报预警 / 中置信 / 推理链降级 | 生成草稿 + 标注复核点 |
| C 拦截整改 | 危险品 / 管制参数 / 要素必填缺失 / 三单容差超限 | 阻断并给出整改清单 |

商标词命中只作为线索升级到 B 级提示人工核查授权，**不自动判定侵权**——"适用于 iPhone"的兼容性描述与假货都可能命中品牌词，判定权留给人。

### 法规知识库（RAG）

- 324 检索块（BM25 + 同义词扩展 + 状态过滤），16 张规则卡 / 256 条款
- 回答必须带条款出处，受约束生成，不允许自由发挥
- 税号承继链：8507600090（superseded）→ 8507600099（active），归类检索自动跳过作废税号

### 知识资产

| 资产 | 规模 | 来源 |
|---|---|---|
| HS 税号库 | 13 条（11 active / 1 superseded / 1 needs_review） | 2026 版税则 |
| 申报要素库 | 13 键 / 113 要素 / 必填 84 | 单一窗口申报参数 |
| 禁限管制参数 | 识别码 707 条 / 申报要素 128 条 | 2026 年第 40 号公告 |
| HS 管制映射 | 6,812 编码 | 与管制参数交叉验证 230/230 一致 |
| 字段字典 | 6 段 37 栏（含 40 号公告新增 2 栏） | 填制规范 |

以上数据均为海关公开文件的整理结果，入库脚本见 `data_import/`。

## 快速开始

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements_local.txt

cp .env.example .env   # 填入 DEEPSEEK_API_KEY（不填也能跑，归类置信度封顶 medium）

python -m web.api.server   # 打开 http://127.0.0.1:8000
```

Web 界面内置四个演示场景：

| 场景 | 贸易方式 | 预期分流 |
|---|---|---|
| 核心演示一 · 合规直通 | 9610 零售出口 | A 级（硅胶手机壳，无品牌，单价正常） |
| 核心演示二 · 低报复核 | 9610 零售出口 | B 级（单价 0.18 美元低于阈值，转人工） |
| 独立测试一 · 商标线索 | 一般贸易 | B 级（商品描述含 iPhone，提示核查授权） |
| 独立测试二 · 危险品硬边界 | 一般贸易 | C 级（锂离子充电宝 UN3480，强制拦截） |

## 边界（诚实声明）

- 覆盖品类有限：HS 税号库目前 13 条，非全税则
- OCR 依赖 VLM，无 Key 时降级为 JSON 直读
- 未实现出口地报关、退税申报等环节
- LLM 归类置信度 medium 时强制 B 级，不允许自动拟单
